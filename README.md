# تطبيق مطبخ لانا (أندرويد + طباعة شبكة أو USB)

**الإصدار الحالي: 1.1 (versionCode 2)** — يتضمن الطباعة عبر الشبكة وعبر USB مع OTG.

يفتح شاشة المطبخ من الموقع، ويطبع الطلبات تلقائياً بالعربي بمقاس 80mm — بدون كمبيوتر.

طريقتان للتوصيل (تختار أحدهما في إعدادات التطبيق):
- **الشبكة (واي فاي):** الطابعة موصولة بالراوتر بكابل شبكة، ويُدخل عنوان IP في التطبيق. (الأفضل والأثبت)
- **كابل USB:** الطابعة موصولة بالتابلت مباشرة عبر كابل OTG. يطلب التطبيق إذن USB عند أول إعداد.

## بناء ملف APK (مرة واحدة)
1. نزّل وثبّت Android Studio على أي كمبيوتر (على ماك Apple اختر نسخة "Mac with Apple chip").
2. افتح المجلد `android-print-app` من Android Studio (Open).
3. انتظر حتى ينتهي التحميل، ثم من القائمة: Build → Build APK(s).
4. الملف يظهر في `app/build/outputs/apk/debug/app-debug.apk` — انقله للتابلت وثبّته.

أو عبر GitHub تلقائياً: الملف `.github/workflows/build-apk.yml` يبني الـ APK مع كل رفع، من تبويب Actions ← Artifacts.

## التشغيل على التابلت
1. وصّل الطابعة: بكابل شبكة للراوتر، أو بكابل OTG إلى التابلت للطباعة عبر USB.
2. افتح تطبيق «مطبخ لانا» واضغط زر «⚙ الطابعة».
3. الصق رمز الطابعة (من لوحة الإدارة ← الطابعات)، واختر طريقة التوصيل:
   - شبكة: أدخل عنوان IP الخاص بالطابعة.
   - USB: وافق على إذن USB الذي يظهر.
4. من لوحة الإدارة اضغط «طباعة تجريبية» للتأكد.

ملاحظة: التطبيق يجب أن يبقى مفتوحاً (الشاشة تبقى مضاءة تلقائياً). وإذا كان برنامج الطباعة على الكمبيوتر ما زال يعمل بنفس الرمز فأطفئه، حتى لا يأخذ الطلبات قبل التابلت.
